# ProxyNode2

**ProxyNode** — клиентская часть системы проксирования запросов, работающая совместно с **ProxyHub**.  
Позволяет перенаправлять API-запросы через центральный сервер (**ProxyHub**) на узлы, доступные только во внутренней сети клиента.

---

## Архитектура

Система состоит из двух компонентов:

- **ProxyHub** — центральный сервер, разворачивается в единственном экземпляре.
- **ProxyNode** — клиентский агент, запускается на стороне клиента.

Принцип работы:
1. **ProxyNode** подключается к **ProxyHub** и регистрируется в нём.
2. API-запросы, отправленные на **ProxyHub**, пересылаются на соответствующий **ProxyNode**.
3. **ProxyNode** перенаправляет запрос на целевой узел в сети клиента.
4. Ответ проходит в обратном направлении:  
   `узел клиента → ProxyNode → ProxyHub → клиент API`.

---

## Конфигурация ProxyNode

### Файлы конфигурации

При первом запуске ProxyNode (JAR-файл) в рабочей директории создаются **два** файла конфигурации: `proxy_conf.txt` и `proxy_id.txt`.
Предполагается что proxy_conf.txt содержит общие настройки для множества драйверов и уже заполненный устанавливается на несколько нод.
А proxy_id.txt создается уже на каждой конкретной ноде отдельно и содержит данные уникальные в рамках конкретной ноды.


#### proxy_conf.txt — основной файл конфигурации

Содержит настройки версии ноды, подключения к ProxyHub и конфигурацию драйверов:

```ini
# Версия ноды и конфигурации (отображается на дашборде ProxyHub, и служит для контроля обновления каждой из нод)
node_version=s1.0 (pn1.7.0)

# Теги ноды для фильтрации (опционально, через запятую)
node_tags=ie,flanium

# Адрес сервера Proxy Hub (без http/https), например: 123.456.7.8 или proxyhub.lanit.ru
server_url=127.0.0.1

# Порт сервера Proxy Hub (0 — если не нужен)
server_port=4448

# Поддержка https/wss (true/false)
https=false

# --------------------------------------------------------------------------------
# Настройки драйверов (каждый драйвер имеет префикс d0, d1, d2 и т.д.)
# --------------------------------------------------------------------------------
# driver_url  — IP/адрес драйвера (рекомендуется запускать ProxyNode там же, где и драйвер)
# driver_port — Порт драйвера
# driver_name — Имя драйвера для проксирования запросов к конкретному драйверу
#               Если не указывать имя драйвера при обращении к ProxyHub, используется драйвер d0.
# before_script_path — Путь до исполняемого скрипта, запускаемого перед каждой сессией

d0.driver_url=127.0.0.1
d0.driver_port=9999
d0.driver_name=default
d0.before_script_path=

d1.driver_url=127.0.0.1
d1.driver_port=9998
d1.driver_name=ie
d1.before_script_path=

d2.driver_url=
d2.driver_port=
d2.driver_name=
d2.before_script_path=
```

#### proxy_id.txt — идентификационные данные ноды

Содержит уникальный идентификатор и дополнительные теги/описание:

```ini
# Уникальный id ноды (генерируется автоматически при создании файла)
node_id=0a54ea15-6b0b-4141-b0c5-35efcbd21fb8

# Теги текущей ноды, объединяются с тегами из proxy_conf.txt.
# Используются для фильтрации всех запущенных нод (опционально, через запятую).
node_tags=win1272,windows,regress,more_tag,more_tag2

# Описание ноды (отображается на дашборде ProxyHub, опционально)
node_description=Описание текущей ноды
```

## Режимы работы

ProxyHub поддерживает два режима проксирования:

### 1. Режим подключения по ID (для отладки)

Прямое подключение к конкретной ноде без учёта её занятости.

Формат URL:
```
https://<server_url>:<server_port>/proxy/id/<node_id>
```

Пример: 
```
https://proxy.example.com:4448/proxy/id/0a54ea15-6b0b-4141-b0c5-35efcbd21fb8
```

### 2. Режим подключения по тегу

Запуск на случайной свободной ноде с указанным тегом.

Формат URL:
```
https://<server_url>:<server_port>/proxy/tag/<tag_name>
```

Пример:
```
https://proxy.example.com:4448/proxy/tag/chrome
```

Для запуска на определённом драйвере необходимо добавить следующие Capabilities:

```json
{
    "proxy_options": {
        "run_id": "<уникальное имя запуска>",
        "driver_name": "<имя драйвера>"
    }
}
```

## Установка и запуск

### Требования:

- Java 17 или новее (JRE/JDK)
- Доступ к серверу ProxyHub
- Сетевой доступ к целевому узлу с машины, где запущен ProxyNode

### Инструкция по запуску:

1. Убедитесь, что установлена Java 17+
    ```
        java -version
    ```
2. Скачайте файл ProxyNode.jar
3. Поместите JAR-файл в отдельную директорию
4. При первом запуске автоматически создадутся файлы `proxy_conf.txt` и `proxy_id.txt`
5. Отредактируйте оба файла, указав параметры подключения
6. Запустите ProxyNode:
    ```
       java -jar ProxyNode.jar
    ```
